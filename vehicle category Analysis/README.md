# Vehicle Registration Analysis - Maharashtra (2019-2024)

This notebook contains an exploratory data analysis (EDA) of vehicle registration data in the state of Maharashtra. It utilizes transport department datasets to visualize trends in vehicle categorization, registration velocity, and regional hub performance.

## 📊 Project Scope

The notebook processes and visualizes registration data through the following operations:

* **Data Preprocessing:** Cleaning and formatting temporal data and vehicle classification mapping.
* **Exploratory Data Analysis:** Aggregating registration volumes by date, vehicle type, and RTO office location.
* **Visual Reporting:** Generation of plots including:
* Log-scale distribution of vehicle types.
* Longitudinal registration velocity (monthly trends).
* RTO volume concentration and commercial fleet density maps.
* Seasonal pattern analysis and growth trajectory projections.
* Comparative analysis of personal vs. commercial vehicle segments.



## 📂 Data Source

The dataset is sourced from the [India Data Portal - MoRTH Vahan Registration by Vehicle Category](https://indiadataportal.com/p/vehicle-registrations/r/morth-vahan_reg_by_vehicle_category-ol-mn-aaa).
